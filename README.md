### 🛒 Shopping Tracker Project

A simple and modern shopping expense tracker built with vanilla JavaScript.  
This project helps users add products, track prices, categorize items, and store data using Local Storage.

<img width="1366" height="635" alt="image" src="https://github.com/user-attachments/assets/56742657-bc8b-4113-9143-11649ea5312a" />

---

#### 🚀 Features

- Add products with name, price, and category
- Delete products from the list
- Mark products as completed
- Automatic total price calculation
- Data persistence using Local Storage
- Clean and modern UI design

---

#### 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API
